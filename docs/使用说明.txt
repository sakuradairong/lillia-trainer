莉莉娅中文修改器 v2.1.0 使用说明

请使用“莉莉娅中文修改器.exe”（v2.1.0），包含仓库扩容与一键替换套装。启动前关闭旧修改器。

【仓库扩容】
  · 在“背包”页底部选择仓库，输入目标列数、行数，点击“应用扩容”。
  · 支持仓库/服装、消耗品仓库和杂物仓库三类；每边最多 256，总容量最多 4096 格，仅允许扩大。
  · 保留现有物品的位置。扩容后请在游戏内保存，再重新载入存档，让仓库网格按新尺寸重建。
  · 物品已经超出旧网格时，只要坐标有效且目标容量足够，也允许扩容；界面会显示物品所需最小尺寸。
    目标布局按物品实际占位校验：例如损坏的 10x80 服装网格，要扩到 10x160 至少需要 10x133。
  · 仓库尺寸不进入通用撤销；未保存前可以重新载入存档恢复原尺寸。

【一键替换套装】
  · 程序已内置换装组件。
  · 先在游戏中打开基地换装界面；修改器进入“服装图鉴”，选择系列和配色，点击“一键替换套装”。
  · 只替换本存档已有的可穿戴部件，不解锁未拥有服装；同槽位的组合服装和重复件会自动避开冲突。
  · 保留发型、本系列未覆盖的部位和其他套装预设；冲突部件换下后返回仓库，空位不足会拒绝操作。
  · 游戏会刷新角色外观，请等加载完成后确认，并在游戏内手动保存。
  · 换装结果会保留在按钮旁；原始失败原因自动记录到程序目录下的 trainer\outfit.log。
  · 套装替换不进入修改器的通用撤销缓冲。不要同时运行多个修改器或连续重复点击。

【v2.1.0 修复】
  · v2.1.0 程序为“莉莉娅中文修改器.exe”。请关闭旧修改器窗口后再启动。
  · 统计数组按字段固定元素类型，并校验实际数组类型与下标；不能手动切换类型。
  · 每次锁定写入前重新确认存档及进程身份，发生切换时拒绝旧锁定并清除撤销数据。
  · 进阶页可滚动访问底部的统计数组和结局状态。
  · 跨容器移动暂不可用：目标网格、容量和物品状态规则未完全验证，请在游戏内移动。

【v2 更新】
  · UI 全面重设计：左侧导航（概览 / 资源与锁定 / 背包 / 任务 / 服装图鉴 /
    进阶数据）+ 圆角卡片式布局 + 顶部状态胶囊。
  · 新增「概览」仪表盘：金币 / 精液储量 / 天数 / 等级 / 地图耐力 /
    背包 / 任务 / 服装解锁 一览，含当前穿搭与发型收藏。
  · 新增「服装图鉴」：36 系列服装目录（提取自游戏资源目录 catalog.json，
    共 421 个服装缩略图键），自动对比当前存档的拥有状态并列出未解锁清单。
  · 背包提供既有物品数量和补满操作；跨容器移动按钮保持禁用。

1. 启动顺序
   先运行游戏并载入一个存档，再运行“莉莉娅中文修改器.exe”。
   顶部显示“已连接 · 存档已载入”后，各项功能才可用。

2. 修改与生效
   在“资源与锁定 / 背包 / 任务 / 进阶数据”页修改数值，点击对应“应用”。
   修改只写入内存，必须在游戏内手动保存（Save）后才会保留到存档文件。

3. 备份
   点击顶部“备份存档”，会在本地生成带时间戳的存档副本。
   备份只复制文件，不会改动游戏正在使用的存档。

4. 锁定
   勾选“资源锁 / 全耐力锁 / 无限天数”后会按 0.5 秒周期持续写回设定值。
   全耐力锁需要角色在地图内，角色不存在时该项不可用。
   取消勾选即可停止；连接断开或切换存档时，锁定会自动清除。

5. 撤销
   “撤销”只覆盖当前存档的标量字段（金币、资源、日期、难度、
   体型、最大耐力、若干掩码/计数等）。背包物品、任务进度、角色、数组、
   仓库扩容与套装替换等其它修改不会进入撤销缓冲，请自行用第 3 步的备份恢复。
   同一地址只保留第一次修改前的原始值。

6. 服装图鉴说明
   目录共 36 系列。拥有判定规则：该系列任一部件物品存在于
   背包 / 仓库 / 秘密口袋 / 发型槽 / 已装备槽（商店柜台不计入）。
   未解锁系列在界面中以红色标出，可在游戏内商店、地图拾取点
   或活动事件中获取。兔子警察服装对应存档解锁标志，
   可在“进阶数据”页勾选“兔子警察已解锁”。

7. 范围与限制
   仅支持界面中列出的功能；不提供无敌、免警察等效果。
   不修改任何存档文件内容，也不提供离线存档破解。
   存档切换或游戏重启后，请先点击“立即刷新”再继续修改。
